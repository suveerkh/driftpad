# Driftpad

Floating notes for macOS that live in the menu bar.

## Run

    swift run

A note icon appears in the menu bar.

- Left-click: new floating note
- Right-click (or Control-click): menu with New Note and Quit
- Drag a note by its top strip; X closes it

Requires macOS 14+ and the Swift toolchain (`xcode-select --install`).
